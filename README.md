# 📐 React Básico - Calculadora
Projeto de revisão de React básico, criado para praticar a criação de componentes, uso de props, composição visual e renderização dinâmica com JavaScript.

Neste projeto, desenvolvi uma calculadora simples com layout estilizado, utilizando React em um arquivo HTML e Tailwind CSS via CDN para reforçar os fundamentos da biblioteca.

⚙️ O objetivo foi aplicar conceitos essenciais como:
- componentização
- props e children
- composição de layout
- uso de classes dinâmicas
- estrutura básica de um projeto em React

É um exercício para revisar os primeiros passos no React e consolidar a base da criação de interfaces com JavaScript.

## Tecnologias utilizadas
- HTML
- React via CDN
- Tailwind CSS via CDN
- JavaScript

## Objetivo do projeto
Reforçar conceitos iniciais de React, como:
- criação de componentes
- reutilização de elementos
- estilização com classes
- organização da interface em blocos

## Como executar
1. Abra o arquivo `4-calculadora.html` no navegador.
2. Certifique-se de que sua conexão com a internet esteja ativa para carregar os scripts do React e do Tailwind.

## 📌 Observação
Este projeto foi desenvolvido como uma revisão prática de React básico, sem uso de bibliotecas ou ferramentas adicionais, focando na compreensão dos conceitos fundamentais.
